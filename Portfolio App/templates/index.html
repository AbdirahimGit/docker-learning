About This Project

I built this application as part of my journey into DevOps. The application uses Flask for the web layer, Redis for storing visitor data, Nginx as a reverse proxy, and Docker Compose to run the services together.

What I'm Learning

I'm using this project to get hands-on experience with containerization, networking, persistent storage, reverse proxies and application monitoring.

Docker Docker Compose Linux Flask Redis Nginx Git CI/CD

Application Architecture

Incoming requests are handled by Nginx and forwarded to the Flask application. Flask communicates with Redis over the Docker network, while Redis data is stored using a Docker volume.
